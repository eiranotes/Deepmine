# DeepMine 게임 디자인·리텐션 검토

- 검토일: 2026-07-29
- 기준 문서: `docs/SPEC_v0.2.md`
- 범위: 코어 루프, 리텐션, 잠금화면 정보 설계
- 상태: 설계 검토 완료, P0 실기기 게이트 전 기능 구현은 보류

## 결론

DeepMine의 리텐션 기반은 이미 좋다. 집중하지 않은 시간에 보상을 주지 않고, 세션 중에는 방해하지 않으며, 완료 후에만 광맥과 성장을 공개한다. 여기에 퀘스트·시즌·소셜·수집품을 서둘러 추가하는 것보다 **귀환 순간의 보상 전달**, **세션 길이 간 공정성**, **다음 1~3회 목표의 가시성**을 먼저 완성해야 한다.

핵심 리텐션 문장은 다음과 같다.

> 오늘 더 오래 붙잡아 두는 게임이 아니라, 내일 다시 한 번 믿고 켤 수 있는 광산.

## 현재 사양이 이미 가진 리텐션 자산

| 자산 | 플레이어에게 주는 이유 | 유지할 원칙 |
|---|---|---|
| 90초 체험 채굴 | 권한 요청 전에 제품의 보상 감각을 이해시킴 | 첫 실행에서 설명보다 완주를 먼저 제공 |
| 15/25/50분 선택 | 일정에 맞춘 작은 약속을 만들 수 있음 | 긴 세션을 강요하지 않음 |
| 안전/심층/탐사 계획 | 같은 시간에도 선택과 긴장을 만듦 | 위험과 보상을 시작 전에 명확히 표시 |
| 종료 시 광맥 공개 | 세션을 방해하지 않는 기대감을 만듦 | 중간 푸시·가짜 발견 연출 금지 |
| 추천 강화 | 귀환 직후 다음 선택을 한 개로 좁힘 | 여러 CTA로 보상을 가리지 않음 |
| 일일 목표·휴광일 | 생활 리듬에 맞춘 장기 목표를 만듦 | 실패 시 0 초기화 같은 처벌 금지 |
| 지역·프레스티지 | 여러 날에 걸친 장기 방향을 제공 | 초기 성장 정체 전에 미리 예고 |
| 잠금화면·StandBy·DI | 앱을 열지 않아도 세션을 신뢰하게 함 | 확인 표면이지 상시 게임 화면이 아님 |

## 우선 해결할 게임 디자인 문제

### 1. 귀환 보고서가 코어 루프의 주인공이어야 한다

사양에는 보상식, 광맥, 추천 강화가 정의되어 있지만 완료 직후 6초의 감정 곡선은 아직 충분히 구체적이지 않다. Phase 2에서 다음 3박자로 고정하는 것이 좋다.

1. **0–1.2초 · 귀환 확인:** 완료 등급과 실제 집중 시간을 한 줄로 확정한다.
2. **1.2–3.5초 · 채굴 결과:** 광석과 광맥을 한 번에 공개한다. 광맥이 없을 때도 기본 보상은 충분히 손에 잡히게 보여준다.
3. **3.5–6초 · 다음 약속:** 다음 지역/장비까지 남은 진척과 추천 강화 하나만 보여준다.

`다시 출정`을 유일한 종료 수단으로 만들면 과사용 압력이 된다. `마치기`와 `다음 출정 준비`는 같은 위계로 제공하고, 성공 지표도 즉시 재시작률이 아니라 다음날 복귀와 주간 집중 시간으로 둔다. 이는 사양 §19.2의 즉시 재시작 지표 폐기와 일치한다.

### 2. 현재 세션 카운트 기반 성장은 긴 집중에 불리할 수 있다

사양 §4.2와 §4.5의 `totalSessions` 기반 성장에서 40세션은 선택 시간에 따라 필요한 실제 집중량이 크게 달라진다.

| 길이 | 40세션 실제 집중 | 보상 배율 |
|---|---:|---:|
| 15분 | 600분 | ×1.00 |
| 25분 | 1,000분 | ×1.10 |
| 50분 | 2,000분 | ×1.30 |

50분 집중은 15분보다 3.33배 길지만 기본 배율은 1.3배다. 장비·심도까지 세션 수에 강하게 묶이면 플레이어는 실제 목표와 반대로 짧은 세션을 반복하는 것이 유리하다고 학습할 수 있다.

Phase 2 전에 다음 중 하나를 시뮬레이션으로 선택해야 한다.

- 25분을 1.0으로 한 **집중 크레딧**을 성장식에 사용한다.
- 세션 횟수는 기록하되 심도·프레스티지는 가중 집중량을 사용한다.
- 짧은 세션의 접근성은 유지하고 1일 첫 세션만 횟수 보너스를 주는 혼합식을 사용한다.

목표는 50분을 우대하는 것이 아니라, 어떤 길이를 골라도 분당 기대 진행이 납득 가능한 범위에 있게 하는 것이다.

### 3. 심층 갱도 실패와 일일 스트릭의 계약이 충돌한다

사양 §3.2는 심층 갱도 포기 시 `스트릭 유지 실패`, §7은 일일 목표 달성으로 스트릭을 판정한다. 이미 100분 목표를 달성한 뒤 추가 심층 세션을 포기했을 때 당일 스트릭까지 취소된다면, 플레이어는 위험 계획을 피하고 게임을 일찍 닫는 편이 합리적이다.

권장 규칙은 다음과 같다.

- 심층 실패는 **그 세션의 보상과 심층 성공 보너스**만 잃는다.
- 이미 확정된 일일 목표와 스트릭은 소급 취소하지 않는다.
- 일일 목표 미달 상태에서의 심층 실패도 남은 목표 시간만 그대로 남긴다.
- 위험 설명은 시작 전 숫자로 보여주고 완료 뒤에 새 벌칙을 공개하지 않는다.

### 4. 첫 3세션을 하나의 온보딩 호흡으로 설계한다

- **체험 채굴:** 휴대폰을 내려놓고 귀환 보상을 보는 이유를 학습한다.
- **첫 정식 세션:** 깊이와 첫 장비 강화를 확정해 소유감을 만든다.
- **두 번째 세션:** 안전/탐사의 선택 차이를 보여준다.
- **세 번째 세션 완료:** 심층 계획 또는 첫 지역 전망을 열어 중기 목표를 제시한다.

권한은 기능이 필요한 순간에 단계적으로 요청한다. 체험 전에 FamilyControls, AlarmKit, 알림 권한을 한꺼번에 요구하면 광산을 경험하기 전에 시스템 설정 화면이 제품의 첫인상이 된다.

### 5. 희귀 광맥은 확률보다 신뢰가 먼저다

광맥은 유료 뽑기가 아니어도 긴 무획득 구간이 생기면 완료 보상의 신뢰를 해친다. Phase 3에서는 시드 기반 재현성을 유지하면서 다음을 검토한다.

- 같은 등급에서 연속 미발견 횟수가 커질수록 완만하게 보정하는 드라이 스펠 보호
- 광맥 종류별 최근 발견 기록을 이용한 중복 완화
- 실제 확률과 보정 규칙을 과장 없이 설명하는 도움말
- 결제와 확률 상승을 연결하지 않는 원칙

### 6. 다음 목표는 1~3세션 거리로 보여준다

홈에서 먼 프레스티지만 보여주면 오늘의 행동과 연결되지 않는다. `다음 램프 강화까지 1회`, `붕괴 지대까지 약 3회`처럼 현재 선택으로 도달 가능한 한 가지 목표를 보여준다. 정확한 횟수를 보장할 수 없으면 `약`을 붙이고, 숨은 난수로 거리를 늘리지 않는다.

프레스티지는 예상 도달 5세션 전부터 무엇이 초기화되고 무엇이 영구 보존되는지 미리 보여준다. 확인 화면에서 보상보다 손실을 더 명확히 적는다.

## 잠금화면 게임 정보 검토

잠금화면은 리텐션 광고판이 아니라 **세션 신뢰 표면**이다. 앱을 열지 않고도 약속이 지켜지고 있음을 확인할 수 있어야 한다.

| 우선순위 | 진행 중 | 완료 후 |
|---|---|---|
| 1 | 남은 시간 | `귀환 완료`와 실제 집중 시간 |
| 2 | 계획명·현재 지역 | 발견 광맥 또는 기본 보상 |
| 3 | 진행 막대 | 앱에서 볼 다음 보고서 한 줄 |
| 4 | 현재 깊이 | 연속 일수는 가장 낮은 위계 |

현재 P0 컴포넌트는 160pt 안에 세션명, 자동 카운트다운, 진행, 깊이, 예상 광석, 연속 일수를 담고 있어 사양 §9.4의 구조를 충족한다. 다만 제품 단계에서는 `60초 시험 채굴`보다 **계획명과 지역**, `예상 광석`보다 **완료 시 공개될 약속**을 우선하는 편이 게임 맥락을 더 잘 설명한다.

완료 상태는 최대 4시간 남는 수동적 귀환 신호로 활용할 수 있다. 이때 다음 세션 시작을 압박하지 말고 `귀환 보고서가 기다려요` 정도만 표시한다. 강화 선택이나 여러 행동은 160pt 잠금화면이 아니라 앱 또는 Expanded DI에 둔다.

이번 P0에서는 Widget Extension과 화면 캡처가 정확히 같은 `ProbeLockScreenContent`를 공유하고 최대 높이 160pt에서 기본 사양을 확인한다. Simulator의 실제 `Device → Lock` 메뉴가 비활성이라 SpringBoard 잠금화면 합성·시스템 크롭·실제 수명주기는 실기기 게이트로 남긴다.

## 리텐션 백로그

| 우선 | 항목 | 단계 | 확인 지표 |
|---:|---|---|---|
| 1 | 귀환 보고서 3박자 | P2 | 보고서 완료율, 다음날 복귀율 |
| 1 | 세션 길이 성장 공정성 시뮬레이션 | P2 | 길이별 완료율, 분당 진행 편차 |
| 1 | 첫 3세션 온보딩 | P1–P2 | 체험→첫 세션, 1→3세션 전환 |
| 2 | 심층 실패/스트릭 계약 확정 | P3 전 | 계획별 선택률·포기율 |
| 2 | 광맥 드라이 스펠 보호 | P3 | 등급별 최대 미발견 연속 횟수 |
| 2 | 다음 1~3세션 목표 | P2–P3 | 추천 강화 수락률, 다음날 복귀율 |
| 2 | 프레스티지 사전 예고 | P3 | 14일 내 첫 프레스티지 도달률 |
| 3 | 주간 채굴 장부 | P5 | 주간 집중 시간, 주간 복귀일 |
| 3 | 지질 도감 | MVP 이후 | 콘텐츠 이해도; 세션 방해 여부 |

주간 채굴 장부는 무료 사용자에게도 총 집중 시간, 완료 세션, 가장 깊었던 출정을 보여준다. 유료 상세 통계가 추가되더라도 기본 자기 이해를 잠그지 않는다. 지질 도감은 완료한 광맥의 의미를 보존하는 기록이어야 하며, 재화 압박용 인벤토리나 일일 퀘스트로 변질시키지 않는다.

## 윤리적 리텐션 가드레일 (2026-07-31 개정)

> **개정**: 아래 항목 중 피로도 소프트캡과 집중 시간 기반 지표는 D-034로 제거됐다.
> 입력이 인간의 주의였을 때만 성립하던 장치이며, 입력이 데미지로 바뀌면 근거가 없다.
> 메커니즘 없는 주장을 문서에 남겨두지 않기 위해 함께 삭제한다.

피벗 이후에도 유지하는 것:

- 광고 없음, 생산력 직접 판매 없음, 확률과 결제를 연결하지 않음
- 광맥 확률과 보정 규칙을 과장 없이 공개
- 오프라인 진행은 상한과 효율을 문서에 명시하고 숨기지 않음

피벗으로 제거한 것:

- 240분 이후 피로도 소프트캡 (D-034)
- 일일 목표·휴광일·스트릭 절반 감소 (집중 분 목표를 전제함)
- 주간 집중 시간 지표

## 2026-07-30 리텐션 2차 반영

리뷰에서 확인한 두 가지 빈칸을 채웠다.

**1~3세션 거리**: 홈의 다음 약속 한 줄을 장비·지역·연속 일수 세 걸음 진행률로 확장했다.
장비는 남은 출정 횟수를 `약 N회`로 추정하고, 추정할 수 없으면 숫자를 만들지 않는다.

**몇 주~몇 달 거리**: 도전과제 30종과 광맥 도감을 넣었다. 미달성 항목도 조건과 진행률을
보여 장기 목표가 화면에 존재하게 한다. 클리커의 "잠긴 업그레이드 목록"이 주는 동력을
제품 정체성 안에서 재현하는 장치다.

쿠키클리커식 지수 성장 감각에 대한 판단도 기록한다. 복리 전환으로 곡선 자체는 생겼다
(드릴 1→60에서 ×14,257). 다만 클리커의 되먹임 — 생산이 오르면 대기가 줄어드는 구조 — 는
"집중만이 연료"라는 정체성과 양립할 수 없다. 세션 길이는 장비를 60레벨로 올려도 줄지
않으므로, 성장의 보상은 가속이 아니라 숫자와 해금뿐이다. 이는 대가가 아니라 선택이며
바꾸지 않는다. 대신 곡선을 **볼 수 있게** 만드는 데 투자했다: 출정 1회 광석 추이, 장비
상위 레벨 목표치, 광부 수, 도감.

아이들링 대 뽀모도로 비중은 시간 기준 2:98, 정체성 기준 5:95, 동기 구조 기준 30:70이다.
이 비중은 의도된 것이고 유지한다. 문제는 비중이 아니라 20%의 게임이 20%만큼도 보이지
않았던 것이었다.

## 구현에서 확정한 결정

1. 심도·프레스티지는 세션 수가 아니라 `집중 분 / 25` 집중 크레딧을 사용한다.
2. 심층 실패는 해당 세션 보상만 잃고 이미 획득한 일일 목표와 스트릭을 되돌리지 않는다.
3. 귀환은 약속 이행 → 보상/광맥 → 다음 약속의 3박자이며 `마치기`와 `다음 출정 준비`는 동등하다.
4. 광맥은 4회 미발견 이후 확률을 보정하고 8번째 적격 완료에서 보장하며 규칙을 플레이 문서에 공개한다.
5. 주간 집중·완료·최고 심도·계획 비율·광맥 이력은 무료다. StoreKit과 유료 상세 통계는 미구현이다.

퀘스트, 시즌, 소셜 경쟁, 캐릭터 수집은 현재 MVP에 추가하지 않았다. D1/D7, 권한 거부군 완료율, 세션 길이별 포기율을 실제 출시 데이터로 확인한 뒤에만 새로운 시스템을 검토한다.
