# Changelog

## Unreleased

### Added

- 클리커 우선 첫 실행. 신규 플레이어가 첫 화면에서 실제 지표 암반을 탭하고 4m를 연 뒤
  광석 100·수정 1개를 받아 드릴 2레벨을 구매한다. 타격과 보상은 즉시 저장된다
- 온보딩 갱도를 하나의 접근성 버튼으로 합쳐 장식 레이어가 중복 버튼으로 읽히지 않게 했다
- 한국어·다크·medium 첫 암반 시뮬레이터 증거 `artifacts/ui/onboarding-clicker-first/first-rock.png`
- 연속 심도 갱도. 4m 경제 세그먼트를 화면 행으로 그리지 않고 지역 단위의 큰 지층을 가운데
  보어가 관통한다. 진행률 동안 굴착 헤드가 실제로 내려가고 위쪽에는 균열과 지나온 길이 남는다
- 장비 레벨 5 분기 6종: 넓은/충격 드릴, 군집/화물 광차, 탐사/행운 램프. 선택은 한 하강 동안
  유지되고 프레스티지에서 초기화된다
- `BoreRecord` 이력. 암반을 부쉈을 때의 보어 폭과 드릴·광차·램프 상태를 보존해 과거 갱도에
  레일·광차·램프와 폭 변화가 누적된다
- 현재 에셋을 재사용한 웹 선행 프로토타입과 연속 하강·장비 시각 계약 테스트 3건, 비공개 배포본
- 생성 갱도 아트 7종. 지역별 와이드 벽면 4종, 지표 캐노피, `ShaftGantry`, `SeamVein`의
  ImageGen 원본·최종 프롬프트·1x/2x/3x PNG·네 안료·알파 검증 결과를 독립 매니페스트로 보존한다
- 작업면 HUD에 탭/자동 데미지, 충격 배율, 다음 광맥층을 추가하고 층 파괴 때 광석 수치와
  파편이 튀는 보상 피드백을 추가했다
- 광산 화면이 세로 갱도 단면이 됐다. 이미 뚫은 갱도가 위에 쌓이고, 작업 중인 막장이
  가운데 고정되며, 미개척 암반이 아래에서 어둠으로 사라진다. 한 층을 부수면 기둥 전체가
  올라가 실제로 내려가는 것처럼 보인다
- 램프 레벨이 아래로 보이는 암반 층 수를 2층에서 최대 8층까지 늘린다. 갱도가 밝아질수록
  더 깊이 보인다
- 좌측 심도 눈금과 지역 진입 명판. 심도가 라벨이 아니라 위치로 읽힌다
- 프레스티지 이후에도 유지되는 **최고 심도**. 장비 상한, 지역 해금, 심도 도전과제가 전부
  최고 기록을 기준으로 한다
- 현재 심도와 최고 심도를 별도 열로 내보내는 밸런스 CSV와 30/180일 새 실측 리포트

### Changed

- 최초 실행 권한 요청을 제거했다. 집중 출정에 필요한 FamilyControls·AlarmKit·알림 권한은
  홈에서 해당 기능을 실제 선택한 시점에만 요청한다
- 제거된 설명 단계의 옛 저장은 같은 실제 첫 암반으로, 옛 권한 단계 저장은 유예 가능한
  레거시 복구 경로로 이어진다
- 심도 눈금을 폭을 차지하는 열에서 좌측 오버레이로 바꿔 가운데 갱도가 오른쪽으로 밀리지 않는다
- 드릴은 도구 티어·보어 폭·파편·스윙, 광차는 레일·왕복 대수·속도·적재량, 램프는 벽면 설비·
  조사 거리·약점 광택으로 수치 성장을 장면에 직접 반영한다
- 기본 홈의 다음 약속·다음 세 걸음·연속 일수 위계를 제거했다. 집중은 접힌 선택 증폭기로
  유지하고 귀환의 “다음 약속”은 “다음 굴착 목표”로 재정의했다
- 홈 화면 순서가 갱도 우선으로 바뀌었다. 집중 출정은 자체 패널을 가진 선택지가 됐고
  더 이상 화면을 여는 주 동작이 아니다
- 프레스티지 자격이 집중 크레딧 40에서 **이번 하강에 부순 암반 120층**으로 바뀌었다.
  집중 권한 없이도 프레스티지와 영구 강화에 도달할 수 있다
- 프레스티지가 위치를 지표로 되돌린다. 장비만 리셋하고 위치를 유지하면 리셋 직후 깰 수
  없는 암반 앞에 서게 되기 때문이다
- 지역 관문이 실제 굴착 속도에 맞춰 깊어졌다. 수정층 120→240m, 폐허 480→800m,
  심연 1200→1600m
- 갱도 암반을 반복 정사각 타일에서 지역별 320×128 와이드 벽면으로 교체하고 지표 입구를
  생성 캐노피로 연결했다. 약점은 36pt 표식과 48×48pt 조작 영역을 분리했다
- 층 파괴 전환을 네이티브 spring으로 바꾸고 Reduce Motion에서는 위치 이동 대신 보상과
  파편을 제자리 교차 페이드한다

### Removed

- 신규 플레이어를 막던 차단 설명 2장, 10초 가짜 채굴 타이머, 강화 뒤 권한 3단계 게이트

### Fixed

- 4m마다 같은 사각 타일을 위에서 덮고 리셋해 광부가 제자리에서만 파는 것으로 보이던 문제
- 별도 심도 열이 갱도 전체를 오른쪽으로 밀어 중심축이 어긋나던 문제
- 장비를 강화해도 숫자와 램프 시야 외에는 장면이 변하지 않던 문제
- 피벗 이전 “약속”과 연속 일수 카드가 클리커 본체보다 먼저 읽히던 홈 정보 위계
- 지표 0~23m에서 음수 심도를 막으면서 굴착 헤드까지 y=0에 붙어 광부·균열이 상단에
  잘리던 문제. 부족한 과거 심도를 지표 위 열린 갱도 여백으로 보충해 작업선을 유지한다
- 일반 탭마다 실제 보상 없이 `+0`이 떠서 타격과 보상의 의미가 섞이던 문제. 일반 탭은
  데미지를, 층 파괴는 획득 광석을 표시한다
- `ShaftGeometry`와 실제 레이어 높이가 달라 심도 눈금·암반 띠가 어긋날 수 있던 문제
- 약점을 한 번 누른 뒤 강조 상태가 계속 남던 문제. 타격 후 120ms에 정상 상태로 돌아간다
- **암반이 갈수록 단단해져 진행이 멈추던 문제.** 400m에서 한 층에 26,000탭, 600m에서
  927,000탭이 필요했고 60일을 쳐도 752m에서 막혔다. 암반 내구 성장률을 1.085에서
  1.058로 낮추고, 장비 레벨 해금을 심도 60m당에서 15m당 1레벨로, 상한을 60에서 200으로
  올렸다. 이제 한 층이 이전 층보다 약 3%씩만 오래 걸린다
- 광석은 남아도는데 살 것이 없던 문제. 심도 잠금이 광석이 허용하는 속도의 3분의 1로
  장비를 묶고 있었다
- 도전과제가 집중 세션·장비 구매·프레스티지에서만 평가돼, 탭으로 이미 지나온 심도의
  배지를 받지 못하던 문제. 암반을 부술 때마다 해소된다
- 탭으로 넣은 데미지가 저장되지 않던 문제. 층이 깨질 때만 저장해서, 수천 탭이 드는
  구간에서 앱이 종료되면 그 층의 진행이 전부 사라졌다. 이제 5초마다, 그리고 층이 깨질
  때와 앱이 배경으로 갈 때 저장한다
- **판 진행이 저장되지 않던 문제.** 암반 위치, 최고 심도, 이번 하강의 부순 층 수, 마지막
  정산 시각이 저장소 스키마에 아예 없었다. 앱을 껐다 켜면 심도가 0으로 돌아갔다
- 광차를 사기 전에는 임팩트 미터가 감쇠하지 않던 문제. 자동화가 없으면 틱 전체를
  건너뛰어서, 14번 탭한 뒤로는 화면을 떠날 때까지 데미지가 2배로 고정됐다
- 밸런스 시뮬레이터가 하루 86,400초를 무제한 자동화로 정산해 실제보다 4배 후한 방치
  수입을 가정하고 탭 수입은 0으로 두던 문제. 이제 실제 8시간 캡과 효율 0.75를 적용하고
  페르소나별 손 채굴을 탭 단위로 시뮬레이션한다
- 프레스티지 뒤 장비 구매 엔진이 현재 위치를 상한으로 읽어 이미 연 6레벨부터 다시 잠그던
  문제. 화면·구매·해금이 모두 최고 심도를 읽는다
- 오프라인 보상을 수령한 뒤 foreground 타이머가 오래된 시작 시각으로 같은 배경 구간을
  다시 자동 채굴할 수 있던 문제
- 심연 깊이 보너스가 HUD 숫자만 움직이고 실제 막장·암반 지역은 옮기지 않던 문제. 이제
  미개척 세그먼트를 실제로 건너뛰고 최고 기록과 지역을 함께 갱신한다
- 홈 집중 패널 재배치 뒤 `mine-home-start`가 화면 밖에 있으면 바로 누르던 UI 테스트.
  최대 5회 스크롤 후 hittable을 단정하는 실제 사용자 경로로 바꿨다

- iPhone 잠금화면 Live Activity가 `medium` 크기라는 이유로 StandBy용 3열 레이아웃을
  사용해 내용이 오른쪽으로 밀리던 문제. 이제 `isActivityFullscreen`일 때만 StandBy를 사용한다
- AlarmKit 타이머를 예약하면서 해당 `AlarmAttributes`용 Widget 구성이 없어 채굴 중
  Dynamic Island가 비어 있던 배선 누락. countdown 전용 Live Activity 구성을 등록했다
- 장비 경제가 레벨 상한 훨씬 전에 정체하던 문제: 드릴·광차 효과를 선형 `+%p`에서 복리로
  전환하고 비용 지수를 `1.38`에서 `1.34`로, 레벨 상한을 20에서 60으로 조정했다. 이제 어떤
  레벨에서도 상대 이득이 +12%로 일정하다
- 프레스티지가 심도를 되돌려 더 많이 집중한 플레이어가 더 얕게 보이던 역전: 심도를 lifetime
  집중 크레딧 기준으로 바꾸고 심연 광맥 보너스도 프레스티지에 유지한다
- 프레스티지가 순손실이던 문제: 이전 최고 장비 레벨을 기억해 재구매 비용을 절반으로 하고,
  조각을 run 크레딧 비례로 지급하며 굴착 기억을 복리로 바꿨다
- Dynamic Island와 위젯의 시작·포기 버튼이 명령만 적재하고 아무것도 실행하지 않던 문제:
  Live Activity intent가 앱 프로세스에서 즉시 명령을 적용한다. 포기 버튼이 차단을 즉시 해제한다
- 화면이 꺼진 기기에서 정직한 세션이 시간 조작으로 오판되던 문제: 시계 소스를 슬립 중
  멈추는 `ProcessInfo.systemUptime`에서 `CLOCK_MONOTONIC_RAW`로 교체했다
- 결석일마다 스트릭이 절반씩 누적 감쇠해 2주 공백이 실질 초기화였던 문제: 결석 기간과
  무관하게 감쇠 1회로 제한하고, 감쇠를 보상 계산 전에 확정한다
- 중도 귀환이 공명 광맥의 다음 세션 ×2를 소진하던 문제: 완료한 세션에서만 소진한다
- 추천 강화가 푸른 광맥만 계산해 램프를 0으로 평가하던 문제: 공명·수정·금고·심연을 포함한
  기대 광석으로 계산한다
- 귀환 보고서의 등급 배지가 완료 화면에서 `준비 완료`로 표시되던 카피 오류
- `dailyRecords`가 무제한 증가하던 문제: 730일 상한을 적용했다
