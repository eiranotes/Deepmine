# Changelog

## Unreleased

### Fixed

- iPhone 잠금화면 Live Activity가 `medium` 크기라는 이유로 StandBy용 3열 레이아웃을
  사용해 내용이 오른쪽으로 밀리던 문제. 이제 `isActivityFullscreen`일 때만 StandBy를 사용한다
- AlarmKit 타이머를 예약하면서 해당 `AlarmAttributes`용 Widget 구성이 없어 채굴 중
  Dynamic Island가 비어 있던 배선 누락. countdown 전용 Live Activity 구성을 등록했다
- 장비 경제가 레벨 상한 훨씬 전에 정체하던 문제: 드릴·광차 효과를 선형 `+%p`에서 복리로
  전환하고 비용 지수를 `1.38`에서 `1.34`로, 레벨 상한을 20에서 60으로 조정했다. 이제 어떤
  레벨에서도 상대 이득이 +12%로 일정하다
- 프레스티지가 심도를 되돌려 더 많이 집중한 플레이어가 더 얕게 보이던 역전: 심도를 lifetime
  집중 크레딧 기준으로 바꾸고 심연 광맥 보너스도 프레스티지에 유지한다
- 프레스티지가 순손실이던 문제: 이전 최고 장비 레벨을 기억해 재구매 비용을 절반으로 하고,
  조각을 run 크레딧 비례로 지급하며 굴착 기억을 복리로 바꿨다
- Dynamic Island와 위젯의 시작·포기 버튼이 명령만 적재하고 아무것도 실행하지 않던 문제:
  Live Activity intent가 앱 프로세스에서 즉시 명령을 적용한다. 포기 버튼이 차단을 즉시 해제한다
- 화면이 꺼진 기기에서 정직한 세션이 시간 조작으로 오판되던 문제: 시계 소스를 슬립 중
  멈추는 `ProcessInfo.systemUptime`에서 `CLOCK_MONOTONIC_RAW`로 교체했다
- 결석일마다 스트릭이 절반씩 누적 감쇠해 2주 공백이 실질 초기화였던 문제: 결석 기간과
  무관하게 감쇠 1회로 제한하고, 감쇠를 보상 계산 전에 확정한다
- 중도 귀환이 공명 광맥의 다음 세션 ×2를 소진하던 문제: 완료한 세션에서만 소진한다
- 추천 강화가 푸른 광맥만 계산해 램프를 0으로 평가하던 문제: 공명·수정·금고·심연을 포함한
  기대 광석으로 계산한다
- 귀환 보고서의 등급 배지가 완료 화면에서 `준비 완료`로 표시되던 카피 오류
- `dailyRecords`가 무제한 증가하던 문제: 730일 상한을 적용했다

### Changed

- 선택 테마가 홈과 활성 광산 장면에 실제 반영되고, 장비·광맥·장식·자원·영구 강화·
  온보딩의 generic SF Symbol 자리를 제품 고유 픽셀 아트로 교체했다
- Dynamic Island와 StandBy가 기존 snapshot의 plan/region/vein ID로 지역 배경과
  계획 광부를 선택하며, 알 수 없는 ID는 입구/안전/기존 광맥 스프라이트로 안전하게 폴백한다
- 활성 채굴 중 Live Activity는 AlarmKit countdown 하나가 소유한다. 별도 커스텀 Activity는
  AlarmKit 예약 실패 시 폴백과 귀환 완료 표면에만 사용해 중복·경합을 피한다
- 온보딩 연습 채굴을 90초에서 10초로 단축. 게임을 보기 전에 90초를 기다리게 하는 것은
  온보딩으로서 너무 길다
- 연습 귀환이 수정 광맥을 확정 발견한다. 확률에 맡기면 대부분의 신규 플레이어가 이 게임의
  핵심 기대감을 첫 실행에서 보지 못한다. 푸른 광맥이 아니라 수정인 이유는 연습 광석이
  고정값이어서 ×1.5를 약속하면 지키지 못하기 때문이다


- 도전과제 35종: 첫 걸음, 쌓인 집중, 심도, 꾸준함, 광맥 도감, 장비 장인, 갱도 문 7계열.
  보상은 수정·장식·테마·배지뿐이고 생산력은 절대 주지 않는다 (D-028). 기한·갱신·미달성
  벌칙이 없어 퀘스트가 아니다 (D-029)
- 도전과제 목록: 미달성 항목도 조건과 현재 진행률을 보여 장기 목표를 가시화
- 홈의 다음 약속을 세 걸음 진행률(장비·지역·연속 일수)로 확장. 장비는 남은 출정 횟수를
  `약 N회`로 추정하고, 추정할 수 없으면 숫자를 만들지 않는다
- 광부 표시: 드릴 5레벨마다 갱도의 광부가 늘어 최대 12명. 보상 계산에 관여하지 않는 순수
  성장 증거이며, 늘어난 순간은 장비 화면에서 알린다
- 통계의 성장 곡선: 출정 1회 광석과 12주 스파크라인, 기록 시작 대비 배율. 주간 총량은
  노력과 성장이 섞여 곡선을 가리므로 세션당 값으로 분리했다
- 광맥 도감: 5종의 발견 횟수와 미발견 실루엣
- 장비 화면의 상위 레벨 목표치 한 줄 — 복리 곡선이 처음으로 눈에 보이는 지점


- 홈에 연속 일수와 이번 주 휴광일 상태, 선택한 채굴 계획의 배율·리스크 설명
- 홈에서 추천 강화를 1탭으로 구매하는 경로
- 출정 약속 시트에 광맥을 만날 확률 (탐사 갱도의 유일한 이점이 보이지 않던 문제)
- 귀환 보고서에 이번 출정 심도 증가, 오늘 목표 진행, 연속 일수, 광맥의 실제 수량
- 장비 화면의 심도 해금 상한 안내와 기억된 레벨 할인 표시
- 활성 채굴 화면의 "화면을 끄고 내려놓아도 됩니다" 안내
- 큰 수를 위한 조/trillion 축약 단위
