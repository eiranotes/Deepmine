## 전체 흐름 수정 체크포인트

각 번호는 별도 GitHub 커밋으로 중간 저장했다.

### 1. 홈 추천을 실제 광산 기준으로 변경 — 완료

- 집중 세션 예상 광석 대신 기대 탭 데미지·자동 DPS·암반 광석 배수로 평가
- 홈과 장비 화면이 동일한 `recommendForMining` 사용

### 2. 첫 자동화 광차 우선 — 완료

- 자동 DPS가 0이고 다음 광차가 자동화를 여는 경우 일반 효율 비교보다 우선

### 3. 집중 세션을 실제 `MiningLoop`로 통합 — 완료

- 세션 시간이 현재 암반에 실제 채굴 시간으로 적용
- 실제 광석·파괴 층·심도 증가를 기록
- `ProgressionEngine.apply(creditOre:)`로 지갑 이중 지급 방지
- 사전 예상 보상과 실제 정산이 같은 광산 시뮬레이션 사용

### 4. 귀환 보고를 실제 진행 중심으로 변경 — 완료

- 현재 심도와 이번 세션 하강량을 보상 직후 항상 표시
- 다음 지역 안내가 실제 세션 심도와 연결

### 5. 스트릭을 실제 채굴일 기준으로 변경 — 완료

- 수동·자동 암반 파괴와 생산이 발생한 오프라인 복귀가 채굴일을 생성
- 비세션 채굴은 일일 세션 횟수를 증가시키지 않음

### 6. 통계를 클리커 중심으로 재편 — 완료

- 상단에 현재 심도·평생 파괴 암반·지갑·자동 DPS 표시
- 집중 세션 통계는 보조 패널로 분리

### 7. 수정 소비처 정의 — 완료
