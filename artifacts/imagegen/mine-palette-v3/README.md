# DeepMine four-pigment asset pass

The original ImageGen sources remain in `artifacts/imagegen/game-ui-v2`. This folder records the derived assets used by the restrained mine interface.

## Palette

- Coal `#10100F`
- Shale `#373630`
- Limestone `#E7E0CF`
- Lamp brass `#C58C39`

The three app assets were remapped without dithering. Transparent pixels in `expedition-gear@3x.png` remain transparent and do not count as a pigment.

## Reference boundary

Behance was used as loose inspiration only. The interface borrows the idea of defining a worn industrial material system before individual controls, while the layout, Korean copy, assets, and interactions remain DeepMine-specific.

- Desert Wasteland UI Concept: restrained worn-material system and consistent HUD logic
- Pixel-art game UI: hard pixel edges and compact control silhouettes
- This War of Mine UI: content-led, desaturated game surfaces
